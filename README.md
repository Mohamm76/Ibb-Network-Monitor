# 🌐 نظام المراقبة الذكي لشبكة اتصالات محافظة إب

نظام متكامل ومحترف مصمم خصيصاً لـ **المؤسسة العامة للاتصالات اليمنية - فرع محافظة إب**. يهدف النظام إلى مراقبة وتحليل أداء الشبكة السلكية واللاسلكية ولحظياً في **17 مديرية** رئيسية بالمحافظة، والتنبؤ بالأعطال وازدحام ممرات الـ **MPLS** قبل حدوثها باستخدام تقنيات تعلم الآلة المتقدمة (Machine Learning).

---

## 🚀 ميزات النظام الحالية (التحديث الأمني والبرمجي)

* **🔗 ربط مباشر بقواعد البيانات:** النظام مرتبط بالكامل بسيرفر محلي لقاعدة بيانات **PostgreSQL (pgAdmin)** لقراءة وكتابة السجلات الميدانية لحظياً وبسرية تامة.
* **🔒 حماية أمنية متكاملة:** فصل بيانات الاتصال الحساسة وكلمات مرور قاعدة البيانات عن الكود المصدري باستخدام ملف البيئة الآمن `.env` وضمان عدم رفعها إلى جيت هب عبر `.gitignore`.
* **🧠 ذكاء اصطناعي متقدم (Predictive AI):** استخدام خوارزمية **Random Forest Regressor** للتنبؤ بزمن الاستجابة (`Latency`) وتصنيف حالة الشبكة (طبيعي، ازدحام، عطل حرج) بدقة رياضية عالية مستندة إلى أحمال الشبكة ودرجات حرارة الموقع.
* **📍 خريطة جغرافية تفاعلية:** لوحة تحكم تفاعلية مدعومة بـ `Plotly` لعرض الحالة التشغيلية لمديريات إب الـ 17 بناءً على آخر القراءات المسحوبة من الـ SQL.
* **📈 مؤشرات أداء ذكية (KPIs):** شاشات عرض فورية لحساب متوسطات الاستجابة، ونسب استهلاك حزم الـ MPLS، والإنذارات النشطة.
* **✍️ مدخلات ميدانية مرنة:** لوحة جانبية ذكية تفرض إدخال الأرقام بالصيغة الإنجليزية وتمنع الأخطاء البرمجية أثناء تحديث جداول قاعدة البيانات.

## 🛠️ متطلبات التشغيل والتثبيت المحلي

### 1. استنساخ المشروع

```bash
git clone https://github.com/mohammed-ibb/Ibb_Network_Monitor.git
cd Ibb_Network_Monitor

```

### 2. تثبيت المكتبات البرمجية

```bash
pip install -r requirements.txt

```

### 3. إعداد البيئة الآمنة

أنشئ ملفاً باسم `.env` في المجلد الرئيسي وضَع إعدادات الـ pgAdmin الخاصة بك:

```env
DB_HOST=localhost
DB_NAME=ibb_telecom_db
DB_USER=postgres
DB_PASSWORD=your_private_password

```

### 4. تشغيل النظام

```bash
streamlit run Ibb_Network_Monitor/app.py

```
